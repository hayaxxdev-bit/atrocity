# M1.57 — Signal Session Bootstrap

## Scope

M1.57 creates the lifecycle that restores or creates a Signal session before
the protocol runtime uses it.

States:
- no-session
- loading
- restoring
- validated
- active
- corrupt
- incompatible
- failed

## Restore

`restore(sessionId)`:
1. loads credentials
2. loads persisted session
3. validates schema and basic invariants
4. validates required negotiated server capabilities
5. publishes an `ActiveSignalSession`

No cryptographic mutation is performed by the bootstrap itself.

## Create

`create(sessionId, factory)` validates credentials/capabilities, produces a
record through a caller-provided factory, persists it, and returns the active
session context.

## Boundary

SessionBootstrap does not own:
- Double Ratchet reconstruction
- Noise transport
- connection lifecycle
- protocol feature lifecycle

It decides whether persisted session material is eligible to enter those
layers.
