# M1.38 — Connection Event Bus & Lifecycle Observability

## Scope

M1.38 introduces a canonical lifecycle event stream for the top-level
connection manager.

## Events

- connection.created
- connection.connecting
- connection.socket-open
- connection.noise-handshake
- connection.authenticating
- connection.encrypted
- connection.syncing
- connection.ready
- connection.reconnecting
- connection.failed
- connection.closing
- connection.closed

## Event metadata

Every event includes:
- monotonic sequence number
- timestamp
- connection id
- reconnect attempt
- previous state
- current state
- transition duration where applicable
- failure metadata on failed events

## Ordering

`InMemoryConnectionEventBus` serializes publication through a promise queue,
so slow async subscribers cannot reorder events.

## Ownership

The event bus is observational. Subscribers cannot mutate connection state
through the event contract.

This allows metrics, dashboard, logging, and diagnostics to consume one
canonical lifecycle stream without becoming lifecycle owners.
