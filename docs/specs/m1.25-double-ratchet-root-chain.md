# M1.25 — Double Ratchet Root & Chain State

## Scope

M1.25 introduces the state needed to progress a Double Ratchet session before
DH-ratchet transitions are added.

## Concepts

- Root Key
- Sending Chain Key
- Receiving Chain Key
- Message Key
- send/receive counters
- root-key generation

A chain step derives:
`MessageKey = HMAC(chainKey, 0x01)`
`nextChainKey = HMAC(chainKey, 0x02)`

The precise labels/derivation parameters remain profile-controlled.

## Important limitation

This milestone is intentionally not a complete Signal Double Ratchet.

Deferred:
- DH ratchet key generation/rotation
- header key handling
- skipped message keys
- out-of-order delivery
- message encryption format
- session state persistence
- exact production Signal KDF constants where profile-specific

The root/chain core is therefore not yet suitable for live message sessions.
