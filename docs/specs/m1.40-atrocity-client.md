# M1.40 — AtrocityClient Public API

## Scope

M1.40 introduces the first stable public client facade.

The facade provides:
- `connect`
- `reconnect`
- `disconnect`
- `sendNode`
- `snapshot`
- `diagnostics`
- `onConnectionEvent`
- `dispose`

## Architectural rule

`AtrocityClient` does not own:
- transport implementation
- Noise state
- authentication state machine
- Signal session state
- persistence
- BinaryNode serialization

It delegates those responsibilities to explicit dependencies.

## Public state

The client exposes a deliberately smaller state vocabulary:
- created
- connecting
- ready
- reconnecting
- closing
- closed
- failed

The underlying ConnectionManager retains the detailed lifecycle.

## Capabilities

The facade declares capabilities so consumers do not need to inspect
implementation classes.

## Reuse rule

A client that reaches `closed` is intentionally terminal. Construct a new
client around a new/active connection runtime instead of reopening a disposed
client.
