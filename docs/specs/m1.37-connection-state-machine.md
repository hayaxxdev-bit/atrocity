# M1.37 — Connection State Machine

## Scope

M1.37 introduces the top-level Atrocity connection lifecycle.

## States

`created`
→ `connecting`
→ `socket-open`
→ `noise-handshake`
→ `authenticating`
→ `encrypted`
→ `syncing`
→ `ready`

Failure:
`failed`

Recovery:
`reconnecting` → `connecting`

Shutdown:
`closing` → `closed`

## Ownership

ConnectionManager owns lifecycle sequencing and reconnect policy.

It delegates:
- socket/transport to `transport`
- Noise handshake to `handshake`
- credential authentication to `authenticate`
- BinaryNode stream to `protocol`
- initial data synchronization to `sync`

## Reconnect

Reconnection uses bounded exponential backoff with jitter and a maximum
attempt count.

## Concurrency

Concurrent `connect()` calls share one in-flight promise and therefore do not
open multiple transports.

## Limitation

This milestone does not decide application-specific reconnect triggers,
credential refresh, session migration, or server-side logout handling.
