# M1.18 — ClientPayload Schema & Authentication Bootstrap

## Current reference

The current Baileys `validate-connection.ts` builds a base ClientPayload with:
- `connectType`
- `connectReason`
- `userAgent`
- `webInfo`
- optional `pushName`

Login adds:
- `passive`
- `pull`
- `username`
- `device`
- `lidDbMigrated`

Registration adds:
- `passive`
- `pull`
- `devicePairingData`

The current source hashes the configured app version with MD5 for
`devicePairingData.buildHash`, serializes companion `DeviceProps`, and puts
registration key bundle values into `DevicePairingData`.

References:
- https://github.com/WhiskeySockets/Baileys/blob/master/src/Utils/validate-connection.ts
- https://cocalc.com/github/MR414N-ID/botku2/blob/master/node_modules/%40adiwajshing/baileys/WAProto/WAProto.proto
