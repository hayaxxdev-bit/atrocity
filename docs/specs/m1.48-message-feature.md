# M1.48 — Message Feature Foundation

## Scope

M1.48 creates the first message domain feature above `ProtocolNode`.

It provides:
- message normalization
- stable message identity
- direction
- basic kind inference
- text extraction
- inbound route registration
- message event subscription

## Boundary

`ProtocolNode -> MessageNormalizer -> MessageEnvelope -> MessageEvent`

The feature does not expose transport or crypto details.

## Deliberate non-goals

- media upload/download
- message encryption
- receipts
- retries
- quoting/edit/delete
- group semantics
- disappearing messages
- exact WAProto mapping

Those remain compatibility milestones.
