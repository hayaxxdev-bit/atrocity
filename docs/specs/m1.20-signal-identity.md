# M1.20 — Signal Identity & Signing Primitives

M1.20 adds Ed25519 signing and verification to the crypto provider and
separates identity signing material from X25519 DH material.

## Credential relationships

Identity X25519 key:
- used for DH/key agreement where the target protocol requires it.

Identity Ed25519 key:
- signs the signed-pre-key public key.

Signed pre-key:
- X25519 key pair
- key identifier
- Ed25519 signature over its public key

The resulting signature is now cryptographically real; the M1.19 hash-based
placeholder has been removed.

## Boundary

CryptoProvider owns signing primitives.
CredentialGenerator owns credential composition.
RegistrationBundle owns the target registration shape.

## Not yet complete

This milestone does not claim a complete Signal pre-key bundle or WhatsApp
registration implementation. One-time pre-keys, exact identity semantics,
persistent credential store, and target-specific serialization remain next.
