# M2.21 — Key-Bundle Digest Exchange

Current Baileys queries the server digest through an `encrypt` IQ containing
`<digest/>`. If the digest is unavailable or key-bundle validation cannot
succeed, the socket follows a repair/upload path.

Reference:
https://github.com/WhiskeySockets/Baileys/blob/master/src/Socket/socket.ts

Atrocity M2.21 introduces `KeyBundleDigestExchange`, which:
1. computes an internal local fingerprint;
2. queries the server with the target `encrypt/digest` IQ;
3. parses a binary digest response;
4. returns `match`, `mismatch`, or `repair-required`.

The local fingerprint is explicitly not treated as the confirmed WhatsApp
server digest algorithm. Exact server digest compatibility requires captured
reference vectors.
