# M2.26 — Exact WAMessage Serialization

Current Baileys models `WAMessage` on generated WAProto `IWebMessageInfo` and
serializes that message before handing the resulting bytes to the Signal
repository.

References:
https://github.com/WhiskeySockets/Baileys/blob/master/src/Types/Message.ts
https://github.com/WhiskeySockets/Baileys/blob/master/src/Socket/messages-send.ts

M2.26 establishes an explicit `WAMessageCodec` boundary plus outbound message
normalization and golden-vector support.

The production protobuf codec is injected. The included test double is only
for boundary tests; it is not claimed as WAProto serialization.

Expected reference hex remains unset until captured/generated WAProto vectors
are available.
