# M1.42 — WABinary Semantic Layer

## Scope

M1.42 adds semantic operations above the raw `ProtocolNode` codec.

The codec remains responsible only for turning bytes into nodes and nodes
into bytes.

The semantic layer owns:
- tag predicates
- attribute access
- child lookup
- path traversal
- tree walking
- semantic validation
- common IQ/message/receipt/notification helpers

## Rule

Application code should use semantic helpers instead of duplicating checks such
as `node.tag === "iq"` and raw attribute access throughout the codebase.

## Validation

`validateNode()` produces structured issues instead of throwing, while
`requireAttribute()` and `requireChild()` throw typed semantic errors for
strict paths.

## Non-goal

This milestone does not attempt to define every WhatsApp node or every server
schema. Those will be added as target-specific semantic contracts.
