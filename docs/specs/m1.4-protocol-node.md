# Atrocity M1.4 — Protocol Node Model

## Scope

M1.4 defines the logical protocol-node representation used by Atrocity.
It intentionally does not define byte encoding, dictionaries, framing,
transport, Noise, or WhatsApp-specific wire rules.

## Model

A protocol node contains:
- `tag`
- immutable string attributes
- optional typed content

Content is explicitly one of:
- `nodes`
- `binary`
- `text`

## Invariants

- Nodes are immutable after creation.
- Attributes are immutable snapshots.
- Binary content is copied on construction.
- Nested nodes are normalized into immutable snapshots.
- An empty tag is invalid.
- The node model has no dependency on Baileys.
- The node model has no wire-format knowledge.

## Out of scope

- Binary encoding/decoding
- Token dictionaries
- Length encoding
- WebSocket framing
- Noise encryption
- Message protobuf
