# M1.39 — Connection Health & Diagnostics

## Scope

M1.39 derives a diagnostic health view from the canonical connection event
stream.

## Health components

- transport
- Noise
- authentication
- protocol

Each component exposes:
- status
- score
- last success
- last failure
- consecutive failures
- observed transition latency

## Overall status

`healthy`, `degraded`, `unhealthy`, or `unknown`.

Health is derived state; it is not a second connection state machine.

## Diagnostics

`ConnectionDiagnostics` retains a bounded recent event history and exposes a
single diagnostic report combining:
- connection snapshot
- health snapshot
- recent lifecycle events

## Ownership

ConnectionManager remains the lifecycle authority.

Health and diagnostics are read-only observers.
