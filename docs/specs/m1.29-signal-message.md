# M1.29 — Signal Message Header & AEAD

## Reference

Double Ratchet message headers contain:
- `DH` — the sender's current ratchet public key
- `PN` — number of messages in the previous sending chain
- `N` — the current message number

The message encryption operation authenticates associated data and ciphertext
with the message key.

Reference:
https://signal.org/docs/specifications/doubleratchet/

## Atrocity implementation

M1.29 introduces:
- `SignalMessageHeader`
- internal header codec
- message AEAD adapter
- header-bound associated data
- Signal message encryption/decryption boundary

The header binary encoding is explicitly an **Atrocity internal format**.
It is not claimed to be the production WhatsApp/Signal wire encoding.

## Atomic receive

`SignalMessageCrypto.receiveIncoming()` delegates decryption to the
transaction-safe ratchet receiver. A failed AEAD authentication therefore
rolls back key derivation and skipped-key mutations.
