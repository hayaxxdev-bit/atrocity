# M1.43 — IQ Request/Response Correlation

## Scope

M1.43 introduces a request/response correlation layer for IQ nodes.

An outgoing IQ request is indexed by its `id` until:
- a matching result arrives,
- a remote error arrives,
- a timeout expires,
- an AbortSignal cancels the request,
- transport send fails,
- the client/connection closes.

## Contract

`IqCorrelator` owns only pending request lifecycle. It does not own transport
reconnect or protocol serialization.

`IqClient` attaches the correlator to an inbound node stream.

## Safety

Every terminal path removes the request from the pending registry, preventing
promise and timer leaks.

Duplicate request ids are rejected.

Pending requests can all be rejected during connection teardown.
