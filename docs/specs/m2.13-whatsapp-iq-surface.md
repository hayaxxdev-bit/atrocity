# M2.13 — Exact WhatsApp IQ Surface

Current Baileys uses a generic `query()` transport primitive and builds
target-specific IQ nodes for operations including:
- `xmlns: encrypt`
- `xmlns: passive`
- `xmlns: md`
- `xmlns: w:stats`

Examples include encrypted key-bundle digest requests, pre-key upload,
active/passive initialization, companion-device removal, and WAM statistics.

Reference:
https://github.com/WhiskeySockets/Baileys/blob/master/src/Socket/socket.ts

Atrocity M2.13 introduces target-specific builders for those stable surface
shapes while retaining the generic IqCorrelator/IqClient underneath.

This is a protocol-surface milestone, not yet a complete key-bundle
implementation. Exact field/cardinality vectors remain pending captured
reference fixtures.
