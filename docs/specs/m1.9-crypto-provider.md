# Atrocity M1.9 — Crypto Provider

## Scope

M1.9 defines a cryptographic primitive boundary. Noise and Signal own
protocol/state semantics; this layer owns only primitive operations.

## Initial backend

Node.js `node:crypto`.

## Primitives

- secure random bytes
- SHA-256 / SHA-512
- HKDF
- X25519 key agreement
- AES-256-GCM AEAD

## Invariants

- CryptoProvider has no knowledge of WhatsApp, WABinary, Noise, or Signal.
- Nonces are supplied to the primitive; higher-level state machines own
  nonce lifecycle.
- AEAD authentication failure is surfaced as a typed crypto error.
- Key sizes and input lengths are validated before cryptographic use.
- Private key material is never logged or placed in public events.
- The provider can be replaced by another audited backend without changing
  Noise/Signal state-machine code.

## Important implementation boundary

The X25519 raw-key conversion is an internal Node backend detail. The
public primitive contract works with raw 32-byte keys.

## Out of scope

- Noise handshake
- Signal protocol
- key ratchets
- certificate/signature semantics
- credential persistence
