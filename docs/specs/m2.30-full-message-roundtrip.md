# M2.30 — Full Message Round-Trip Harness

M2.30 is an integration milestone proving the outbound and inbound message
boundaries compose without bypassing their ownership rules.

Pipeline:
`plaintext → serialize → Signal encrypt → WA envelope → outer message → ACK state → extract enc → Signal decrypt → session commit → deserialize → plaintext comparison`

The harness uses injected serializers and Signal implementations. It therefore
tests orchestration and boundary ordering without pretending to be a live
WhatsApp server.

Success requires byte equality between original and recovered plaintext.

This milestone is not a claim of live interoperability or exact current
WAProto/server behavior.
