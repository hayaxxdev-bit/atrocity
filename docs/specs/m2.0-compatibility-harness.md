# M2.0 — Compatibility Test Harness

## Scope

M2.0 introduces the compatibility harness that will be used for exact
WhatsApp interoperability work.

A vector contains:
- id
- kind
- input
- expected output
- optional metadata

Supported canonical vector kinds:
- bytes
- text
- json

## Runner

`CompatibilityRunner` executes vectors through an injected executor and
compares normalized output.

This keeps reference acquisition separate from Atrocity implementation.

## Comparator

Byte vectors are normalized to lowercase hexadecimal.
JSON vectors are recursively key-sorted before comparison.
Text vectors are compared exactly.

## Error model

Vector definition, duplicate ids, decoding, and execution errors are
reported through typed compatibility errors or failed vector results.

## Boundary

The harness is intentionally internal/development tooling. It is exported
through `@hayaxxdev-bit/atrocity/internal`, not the stable package root.

## Next step

M2.1 will use this harness for the exact WhatsApp Noise profile and transcript
vectors.
