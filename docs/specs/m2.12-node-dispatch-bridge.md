# M2.12 — Protocol Node Dispatch Bridge

M2.12 makes inbound node dispatch a first-class runtime component.

Pipeline:

`ProtocolNode`
→ IQ correlation
→ `protocol.node` event
→ `ProtocolRegistry`
→ feature/domain handler

The dispatcher returns whether an IQ response was correlated and which routes
handled the node.

Unmatched nodes remain observable through the canonical `protocol.node` event.

ProtocolRuntime owns the dispatcher instance, so callers do not need to
recreate the inbound pipeline.

This milestone does not decode bytes; byte decoding remains the responsibility
of the WABinary transport adapter before the node enters ProtocolRuntime.
