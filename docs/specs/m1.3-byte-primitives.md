# Atrocity M1.3 — Byte Primitives

## Scope
Bounds-safe byte reading/writing primitives only.

## Invariants
- Readers never read outside the provided byte range.
- Reader lengths must be non-negative safe integers.
- Writers reject values that do not fit their explicit integer width.
- UTF-8 encoding/decoding uses platform-standard TextEncoder/TextDecoder.
- No protocol-specific assumptions live in the byte primitives.
- ByteReader never allocates based on a network-controlled length.
- ByteWriter owns its output buffer and returns a trimmed copy.

## Out of scope
- WhatsApp wire format
- BinaryNode
- token dictionaries
- Noise
- WebSocket transport
- protobuf
