# M1.51 — Receipt Feature

## Scope

M1.51 introduces inbound receipt normalization and a feature route that can
translate receipts into MessageDeliveryTracker transitions.

Supported semantic hints:
- sent
- delivered
- read
- played

Unknown receipt types are represented as `unknown` and do not mutate delivery
state.

## Architecture

`receipt ProtocolNode`
→ `ReceiptNormalizer`
→ `ReceiptEvent`
→ `MessageDeliveryTracker`

The feature owns protocol route lifecycle. The tracker owns delivery state.

## Non-goals

- full WhatsApp receipt schema
- group participant delivery matrix
- per-device receipt semantics
- retry receipts
- server acknowledgement policy
- exact WAProto mapping
