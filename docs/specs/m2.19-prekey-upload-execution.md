# M2.19 — PreKey Upload Execution

M2.19 executes a pre-key upload plan through the generic IQ request/response
layer.

Flow:
`pending-upload → build encrypt IQ → await success → uploaded`

The executor never decides whether an upload is needed. That decision belongs
to `ServerPreKeyReconciler`.

A failed request leaves local keys in `pending-upload`, allowing deterministic
retry without local state getting ahead of the server.
