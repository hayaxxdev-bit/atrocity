# M2.14 — PreKey Upload & Key-Bundle Exchange

Current Baileys performs key-bundle maintenance after authentication, including
checking whether additional pre-keys are required, uploading pre-keys through
an `encrypt` IQ, rotating the signed pre-key when required, and maintaining a
key-bundle digest.

Reference:
https://github.com/WhiskeySockets/Baileys/blob/master/src/Socket/socket.ts

M2.14 separates this into:
- typed Signal key-bundle material
- validation/state store
- WhatsApp pre-key exchange adapter

The target serializer remains injected because exact current WAProto/key-bundle
field mapping must be backed by reference vectors.

No plaintext private key is serialized by the generic bundle validator.
