# M1.56 — Server Capability Negotiation

## Scope

M1.56 converts server capabilities and feature requirements into a negotiated
result.

A feature declares:
- required server capabilities
- optional server capabilities

The negotiator returns:
- enabled/disabled/unsupported/experimental decisions
- reasons
- required-by/optional-for feature lists
- enabled features
- disabled features
- required failures

## Modes

`negotiate()` always returns an inspectable result.

`negotiateStrict()` throws when required feature dependencies are unavailable.

## Boundary

Negotiation does not start or stop features. It produces a decision consumed
by the feature/connection lifecycle.

This keeps capability policy separate from lifecycle mechanics.
