# Atrocity M1.8 — WebSocket Transport

## Scope

M1.8 provides the production transport adapter over a WebSocket-like
implementation.

## Responsibilities

- Open and close WebSocket connections.
- Map WebSocket lifecycle to the Atrocity transport lifecycle.
- Configure binary transport mode.
- Convert incoming binary messages to `Uint8Array`.
- Send opaque `Uint8Array` payloads.
- Normalize transport errors and close metadata.
- Enforce connection and close timeouts.
- Reject concurrent connect attempts.
- Ignore stale websocket generations.

## Non-responsibilities

- WABinary encoding/decoding
- Noise encryption
- Signal encryption
- Authentication
- Message semantics
- Reconnection policy

## Runtime

Node 22+ is the intended runtime. A WebSocket factory can be injected
for tests or alternate runtime implementations.
