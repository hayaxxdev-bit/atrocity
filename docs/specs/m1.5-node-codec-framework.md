# Atrocity M1.5 — Node Codec Framework

## Scope

M1.5 implements codec orchestration around the logical ProtocolNode model.
It does not implement WhatsApp/WABinary wire rules.

## Design

`NodeCodec` owns:
- recursive node traversal
- protocol codec error normalization
- safety limits
- trailing-byte detection

An injected `NodeCodecStrategy` owns:
- tag representation
- attribute representation
- content representation
- exact wire-format rules

## Invariants

- Logical ProtocolNode is independent from wire encoding.
- ByteReader/ByteWriter are independent from protocol semantics.
- Decoder rejects trailing bytes for single-node decode.
- Network-controlled structure is subject to explicit limits.
- Exact WABinary/token/length rules are not embedded in the framework.
- The placeholder strategy is test-only and is not a wire protocol implementation.
