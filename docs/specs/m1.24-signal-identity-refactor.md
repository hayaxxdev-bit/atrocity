# M1.24 — Signal Identity Refactor

## Decision

Atrocity now treats one Curve25519/X25519 identity key pair as the canonical
identity material for the Signal layer.

That key can participate in:
- X25519 Diffie-Hellman
- XEdDSA-compatible signatures

The signed pre-key is also X25519. Its signature is produced through the
XEd25519 boundary using the same identity private key.

## Why this correction matters

The earlier design accidentally created an independent Ed25519 identity key.
That model was incompatible with the XEdDSA/X25519 identity relationship used
by Signal-style protocols.

## New dependency boundary

SignalIdentity
    ├── X25519 DH
    └── XEd25519 signing

SignedPreKey
    └── signed by SignalIdentity

OneTimePreKey
    └── X25519

PreKeyBundle
    └── public projections only

## Limitation

XEd25519 must still pass authoritative vectors before live registration is
enabled. This milestone fixes the identity model; it does not imply complete
WhatsApp registration compatibility.
