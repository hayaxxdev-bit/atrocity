# M1.2 — Foundation Primitives

## Public

- `AtrocityError`
- `ErrorCode`
- `Result<T, E>`
- `AsyncResult<T, E>`
- `isOk()` / `isErr()`

## Internal utility

- nominal IDs for runtime/session/connection boundaries

## Design invariant

Foundation primitives must not know about WhatsApp, Baileys, WebSocket, Noise, Signal, or storage.
