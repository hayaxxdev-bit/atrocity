# M1.52 — Presence Feature

## Scope

M1.52 introduces a protocol/domain boundary for presence.

Inbound:
`presence ProtocolNode → PresenceNormalizer → PresenceEvent`

Outbound:
`PresenceApi → PresenceNodeBuilder → ProtocolNode → sender`

Supported semantic statuses:
- available
- unavailable
- composing
- recording
- paused
- unknown

## Boundary

Presence does not own message state, receipts, transport lifecycle, or
connection reconnect policy.

## Non-goals

- presence subscription protocol
- privacy/visibility policy
- exact WAProto mappings
- per-device presence aggregation
