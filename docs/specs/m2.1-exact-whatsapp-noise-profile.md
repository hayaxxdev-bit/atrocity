# M2.1 — Exact WhatsApp Noise Profile

## Verified reference facts

Current Baileys `master` exposes:
- `NOISE_MODE = Noise_XX_25519_AESGCM_SHA256\\0\\0\\0\\0`
- `NOISE_WA_HEADER = [87, 65, 6, DICT_VERSION]`
- current `DICT_VERSION = 3`

The current source therefore yields the 4-byte header `57 41 06 03`.

Reference:
https://github.com/WhiskeySockets/Baileys/blob/master/src/Defaults/index.ts

Current socket creation passes this header into the Noise handler and uses a
fresh Curve key pair per connection.

Reference:
https://github.com/WhiskeySockets/Baileys/blob/master/src/Socket/socket.ts

## Important compatibility boundary

This milestone verifies profile constants, not the entire handshake transcript.

The exact handshake implementation, key mixing, payload encryption, and
transport transition remain subsequent M2 milestones and must be covered by
vectors before claiming interoperability.
