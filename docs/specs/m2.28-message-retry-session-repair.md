# M2.28 — Message Retry / Session Repair

M2.28 introduces a retry orchestrator that always re-encrypts from plaintext
using current Signal session state.

Normal retry:
`created → inspecting → re-encrypting → resending → completed`

Session repair:
`created → inspecting → session-repairing → re-encrypting → resending → completed`

A failed resend is `failed`; an old ciphertext is never reused.

Session health, rebuild, encryption, node construction, and transport sending
are injected responsibilities.
