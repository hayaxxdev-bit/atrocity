# M2.29 — Inbound Message Decryption

M2.29 adds the inbound encrypted-message path.

Flow:
`to/enc → classify msg/pkmsg → establish/ensure session when needed → Signal decrypt → commit session/ratchet state → decode WAMessage → publish`

The session commit occurs before application publication so a successful
decryption cannot be observed as delivered while the ratchet state is still
unpersisted.

`msg` uses the existing Signal session. `pkmsg` invokes the session coordinator
before decryption.

The exact WhatsApp retry/decryption-error node mapping remains a separate
compatibility surface.
