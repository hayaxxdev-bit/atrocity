# M2.10 — Authenticated Stream Initialization

M2.10 adds the bridge between an authenticated encrypted connection and the
protocol runtime.

Flow:

`authenticated`
→ send stream open
→ receive `stream:features`
→ discover features
→ negotiate server capabilities
→ start ProtocolRuntime
→ `ready`

Ownership:
- ConnectionManager owns connection lifecycle.
- StreamRuntime owns authenticated stream lifecycle.
- ProtocolRuntime owns protocol feature lifecycle.

The stream runtime does not implement Noise, WABinary framing, or feature
handlers. Those remain dependencies.

The exact current WhatsApp stream-open node and feature set remain target
compatibility details and are not fabricated here.
