# M1.55 — Server Capability Model

## Scope

M1.55 converts raw stream feature discovery into a typed server capability
model.

Capabilities include:
- authentication
- iq
- messaging
- presence
- receipts
- media
- groups
- history-sync
- device-sync
- contacts-sync
- experimental

## Feature gating

Protocol features may declare `requiredServerCapabilities`.

The feature manager refuses to start a feature when required capabilities are
missing.

## Boundary

Capability detection is derived from discovered stream features. It does not
claim that the server supports every higher-level operation implied by a
namespace/tag.

Exact WhatsApp capability mapping remains a target compatibility task.
