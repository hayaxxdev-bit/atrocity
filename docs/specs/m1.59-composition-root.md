# M1.59 — Atrocity Composition Root

## Scope

M1.59 introduces `createAtrocityRuntime()` as the explicit application
composition root.

It constructs and wires:
- AtrocityStateStore
- ProtocolRuntime
- ConnectionProtocolAdapter
- ConnectionManager
- ConnectionDiagnostics
- AtrocityClient
- target transport dependency

## Ownership

The composition root creates objects; it does not execute protocol behavior.

ConnectionManager remains the global lifecycle owner.

ProtocolRuntime remains the protocol lifecycle owner.

AtrocityClient remains the application-facing facade.

## Dependency rule

Subsystem constructors remain independently usable for unit tests. The
composition root is the only place where production object graphs are
assembled.

## Deliberate non-goal

This factory does not invent a live WhatsApp handshake, transport, or
credential flow. Those are supplied as dependencies until exact target
compatibility is finalized.
