# M1.54 — Protocol Sync / Bootstrap

## Scope

M1.54 introduces a synchronization boundary after encrypted protocol
transport is established.

Pipeline:
`stream:features`
→ feature discovery
→ bootstrap node
→ initial-state response
→ completed checkpoint

## Components

- FeatureDiscovery
- SyncBootstrap
- SyncCheckpoint

## Boundary

Sync owns initial protocol bootstrap sequencing.

It does not own:
- connection reconnect
- Noise handshake
- credentials
- feature lifecycle
- long-term history synchronization

## Safety

The bootstrap has explicit stage transitions, timeout delegation, and a
checkpoint for observability/recovery.

Exact WhatsApp bootstrap nodes remain target-specific compatibility work.
