# M2.20 — Signed PreKey Rotation Execution

Current Baileys creates a new signed pre-key with `current keyId + 1`, signs
the new public key with the signed identity private key, then sends an
`encrypt` IQ containing `<rotate><skey>...</skey></rotate>`. The new key is
persisted after the server operation succeeds.

References:
https://github.com/WhiskeySockets/Baileys/blob/master/src/Utils/crypto.ts
https://github.com/WhiskeySockets/Baileys/blob/master/src/Socket/socket.ts

Atrocity M2.20 implements commit-after-ack semantics: a newly generated key is
a candidate until the rotate IQ succeeds.
