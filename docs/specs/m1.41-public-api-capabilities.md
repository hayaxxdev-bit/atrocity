# M1.41 — Public API Boundary & Capability Model

## Scope

M1.41 freezes the first public API boundary of `@hayaxxdev-bit/atrocity`.

## Public surface

The stable facade exports:
- `AtrocityClient`
- public client error
- API version
- capability types
- client snapshot
- capability registry

## Capability model

Capabilities are represented as:
- name
- version
- status
- flags

Initial capability names:
- `connection`
- `protocol.nodes`
- `diagnostics`
- `reconnect`
- `media`
- `groups`
- `history-sync`

Only features actually backed by configured dependencies are reported as
`available`.

## Compatibility rule

Internal implementation classes can change without requiring public API
changes, provided the facade contract remains compatible.

Experimental and unavailable capabilities are visible instead of being
silently absent.

## Security/architecture

Capability discovery is descriptive. It does not grant permissions and does
not alter protocol state.
