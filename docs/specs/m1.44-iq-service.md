# M1.44 — Protocol IQ Service

## Scope

M1.44 turns the low-level IQ correlator into a reusable protocol service.

## Public operations

- `get(operation, options)`
- `set(operation, options)`
- `request(node, options)`
- `close()`

## Builders

Canonical IQ builders create:
- get
- set
- result
- error

with a single location enforcing id/type requirements.

## Response decoding

`decodeIqResult()` validates:
1. IQ node shape
2. result vs error semantics
3. custom result decoder

Feature services can therefore map protocol nodes into domain values without
duplicating response validation.

## Boundary

`IqService` owns request/response protocol behavior.
`IqCorrelator` owns pending-request lifecycle.
`WABinaryCodec` owns serialization.

No layer takes responsibility for another layer's concerns.
