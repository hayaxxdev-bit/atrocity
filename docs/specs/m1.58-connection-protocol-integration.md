# M1.58 — Connection ↔ Protocol Integration

## Scope

M1.58 binds the top-level connection lifecycle to the protocol runtime.

The connection sequence is:

`transport.connect`
→ handshake
→ authentication
→ encrypted
→ protocol.start
→ sync
→ ready

Shutdown reverses protocol ownership before transport closure.

## Ownership

ConnectionManager remains the only global lifecycle owner.

`ConnectionProtocolAdapter` provides a narrow stage-specific bridge and does
not implement reconnect, transport, or feature lifecycle.

## Compatibility

The adapter is optional for backwards-compatible composition. New composition
roots should provide it so the lifecycle boundary is explicit.

## Failure

Protocol startup failure propagates through ConnectionManager and transitions
the connection to `failed`.
