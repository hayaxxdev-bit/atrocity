# M1.21 — Signal Pre-Key Bundle

## Scope

M1.21 establishes the Signal pre-key material domain and one-time pre-key
lifecycle.

## Model

`PreKeyBundle` contains:
- registration id
- identity public key
- signed pre-key id
- signed pre-key public key
- identity signature over signed pre-key
- optional one-time pre-key

The private halves never leave the `PreKeyStore` API.

## Lifecycle

Generation:
`Identity → SignedPreKey → OneTimePreKeys → Store`

Consumption:
`Bundle selection → consume one-time key → remove from store`

## Security

- identity signing uses Ed25519
- DH pre-keys use X25519
- store returns defensive copies
- one-time pre-keys are single-use at the store boundary

## Limitation

This is not yet the full Signal protocol. Session establishment, ratchets,
pre-key message construction, and exact WhatsApp identity semantics remain
future milestones.
