# M2.24 — WhatsApp Message Encryption Boundary

Current Baileys first encodes the protobuf `WAMessage`, then calls the Signal
repository with recipient JID and message bytes. The Signal result is mapped
to `msg` or `pkmsg` and placed into a WhatsApp `to`/`enc` binary node.

References:
https://github.com/WhiskeySockets/Baileys/blob/master/src/Socket/messages-send.ts
https://github.com/WhiskeySockets/Baileys/blob/master/src/Signal/libsignal.ts

Atrocity separates:
- WAMessage/Plaintext serialization;
- Signal encryption;
- WhatsApp ciphertext envelope.

No private Signal session key material crosses the envelope boundary.

Exact WAMessage protobuf serialization is deferred to a subsequent WAProto
compatibility milestone.
