# M1.47 — Protocol Runtime

## Scope

M1.47 composes the protocol infrastructure into one runtime boundary.

`ProtocolRuntime` owns:
- ProtocolRegistry
- ProtocolFeatureManager
- IqClient
- inbound node dispatch
- outbound node delegation
- protocol runtime lifecycle

## Inbound

`ProtocolNode`
→ IQ correlation
→ ProtocolRegistry
→ registered feature handlers

## Outbound

Feature/client
→ ProtocolRuntime.sendNode()
→ configured transport sender

## Lifecycle

`created → starting → started → stopping → stopped`

Startup activates all registered protocol features using dependency order.
Shutdown closes IQ correlation and stops features in reverse dependency order.

## Boundary

ProtocolRuntime does not own:
- connection lifecycle
- WebSocket
- Noise handshake
- Signal session
- persistence

Those remain outside the runtime.
