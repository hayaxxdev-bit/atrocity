# M1.61 — Foundation Freeze

## Status

M1 foundation is frozen for the M2 compatibility program.

## Public entry point

`@hayaxxdev-bit/atrocity` exports the stable public facade through
`src/index.ts`.

The infrastructure graph is available only through the explicit internal
entrypoint used by development/integration tooling.

## Frozen ownership rules

1. ConnectionManager owns global connection lifecycle.
2. ProtocolRuntime owns protocol lifecycle.
3. ProtocolRegistry owns inbound routing.
4. ProtocolFeatureManager owns protocol feature lifecycle.
5. ProtocolEventBus is observational.
6. IqCorrelator owns pending IQ lifecycle.
7. MessageDeliveryTracker owns delivery state.
8. Persistence records remain versioned/atomic.
9. Target-specific WhatsApp assumptions stay behind adapters.

## M1 acceptance

The foundation is considered structurally complete when:
- public surface is narrow;
- lifecycle ownership is singular;
- internal event dispatch has no `any`;
- compatibility seams are explicit;
- audit findings are recorded.

## M2 boundary

M2 is responsible for exact WhatsApp compatibility and live interoperability.
M1 abstractions should not be changed merely to add feature breadth; changes
must be justified as a foundation defect or isolated compatibility adapter.
