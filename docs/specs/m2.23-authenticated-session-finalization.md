# M2.23 — Authenticated Session State Finalization

M2.23 creates the commit boundary from successful authentication to an active
persisted runtime session.

Required preconditions:
- authentication exchange accepted;
- post-auth initialization authenticated;
- Signal key bundle available.

Flow:
`authenticated → finalizing → persisting → active`

Persistence failure produces `failed` and does not publish an active session.

The finalizer clones byte material before persistence to prevent caller-owned
mutable buffers from changing the persisted session object.

This is an application/session state boundary; it does not implement Signal
cryptography or connection lifecycle.
