# Atrocity M1.7 — Transport Abstraction

## Scope

M1.7 introduces the transport contract. A transport moves opaque bytes
and owns connection lifecycle. It does not know about WABinary, Noise,
authentication, messages, or WhatsApp semantics.

## States

`idle → connecting → open → closing → closed`

A fatal implementation error may transition a concrete transport to
`failed`.

## Invariants

- Transport payloads are `Uint8Array`.
- Transport does not inspect protocol bytes.
- `send()` is valid only while the transport is `open`.
- Handlers are replaced as an immutable snapshot.
- Received bytes are copied before delivery by the in-memory test transport.
- Close is terminal for a transport instance.
- Protocol/Noise layers sit above this boundary.

## Testing

`InMemoryTransport` exists only as a deterministic test transport.
It is not a production network implementation.
