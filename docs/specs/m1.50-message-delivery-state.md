# M1.50 — Message Delivery State

## Scope

M1.50 separates message delivery lifecycle from message construction and
transport.

Lifecycle:
`created → queued → sent → delivered → read`

Alternative:
`created → queued/sent/delivered → failed`

## Properties

- monotonic delivery progression
- typed transition errors
- terminal failed state until explicit retry semantics exist
- per-message transition serialization
- immutable records/events

## Architecture

`MessageDeliveryTracker` is an application/protocol state observer. It does
not send messages or parse receipts.

A future ReceiptFeature will translate inbound receipt nodes into tracker
transitions.
