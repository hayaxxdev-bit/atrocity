# M1.16 — WhatsApp Handshake Protocol

Current/reference sources define:

HandshakeMessage:
- clientHello = field 2
- serverHello = field 3
- clientFinish = field 4

HandshakeClientHello:
- ephemeral = field 1
- static = field 2
- payload = field 3

HandshakeServerHello:
- ephemeral = field 1
- static = field 2
- payload = field 3

HandshakeClientFinish:
- static = field 1
- payload = field 2

Baileys' current socket path constructs `clientHello` from a fresh ephemeral
public key, decodes `serverHello`, later encrypts a protobuf ClientPayload,
and wraps its Noise outputs in `clientFinish`. It uses generated `WAProto`
protobuf bindings.

References:
- https://github.com/WhiskeySockets/Baileys/blob/master/src/Socket/socket.ts
- https://cocalc.com/github/jajbshjahavahh/Gojo-Satoru/blob/master/node_modules/%40adiwajshing/baileys/WAProto/WAProto.proto

Atrocity implements only this handshake envelope schema here. The complete
ClientPayload schema remains an authentication/registration concern.

This milestone does not claim live compatibility.
