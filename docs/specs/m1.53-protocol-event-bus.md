# M1.53 — Protocol Domain Event Bus

## Scope

M1.53 introduces a typed domain event bus shared by protocol features.

Initial events:
- `protocol.node`
- `message.received`
- `message.sent`
- `message.unknown`
- `receipt.received`
- `presence.received`

## Properties

- typed event payloads
- subscribe/unsubscribe
- once listeners
- per-event ordered async delivery
- listener cleanup
- handler failures converted to typed errors

## Ownership

ProtocolRuntime owns the canonical event bus instance for the protocol
runtime.

Features may publish their domain events into that bus, but the bus does not
own feature lifecycle or transport.

## Non-goals

- cross-process event delivery
- durable event storage
- replay
- event sourcing
