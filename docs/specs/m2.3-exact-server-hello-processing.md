# M2.3 — Exact WhatsApp ServerHello Processing

Current Baileys `noise-handler.ts` processes ServerHello by authenticating the
remote ephemeral, mixing a DH, decrypting/mixing the server static key,
decrypting the certificate chain, verifying the leaf and intermediate
signatures plus issuer serial, encrypting the client Noise public key for
`clientFinish.static`, then performing the final DH mix.

Reference:
https://github.com/WhiskeySockets/Baileys/blob/master/src/Utils/noise-handler.ts

Atrocity now has that sequence as an explicit target adapter.

Cryptographic operations, certificate decoding, and signature verification are
injected dependencies; the adapter owns sequencing only.

No expected handshake key/certificate bytes are fabricated. Exact vectors
remain required before claiming full interoperability.
