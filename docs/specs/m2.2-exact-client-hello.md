# M2.2 — Exact WhatsApp ClientHello

## Reference behavior

Current Baileys constructs a `HandshakeMessage` containing `clientHello` with
the connection's ephemeral public key and serializes that handshake message
before writing it to the socket.

Reference:
https://github.com/WhiskeySockets/Baileys/blob/master/src/Socket/socket.ts

## Atrocity

M2.2 introduces:
- `buildWhatsAppClientHello()`
- `validateEphemeral()`
- `WhatsAppClientHello` codec adapter

The target boundary is explicit: key generation belongs to the Noise/session
layer; ClientHello construction belongs to the WhatsApp handshake adapter;
protobuf/wire encoding belongs to a codec dependency.

## Compatibility status

The semantic structure and 32-byte X25519 public-key boundary are implemented.

The actual wire encoder must be supplied by the exact WAProto-compatible codec
before a byte-for-byte compatibility claim is made.
