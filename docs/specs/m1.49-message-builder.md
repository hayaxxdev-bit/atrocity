# M1.49 — Message Protocol Builder

## Scope

M1.49 creates the first outbound message builder.

Supported operation:
- text message → ProtocolNode

`MessageApi.sendText()` also generates a message id when the caller does not
provide one.

## Boundary

`MessageInput`
→ `MessageNodeBuilder`
→ `ProtocolNode`
→ caller-provided sender

The builder never opens a transport or performs encryption.

## Validation

The builder validates:
- message id
- remote JID
- non-empty text
- 64 KiB text upper bound
- optional participant

The limits are Atrocity-side safety defaults and are not claims about every
WhatsApp server limit.

## Deferred

- exact WA message protobuf semantics
- message stanza attributes required by current WhatsApp
- media
- replies/quotes
- reactions
- message encryption
- receipts
