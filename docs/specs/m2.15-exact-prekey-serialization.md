# M2.15 — Exact PreKey Serialization

Current Baileys `src/Utils/signal.ts` defines `xmppSignedPreKey()` as `<skey>` with a three-byte big-endian id, public value, and signature; `xmppPreKey()` as `<key>` with a three-byte big-endian id and public value.

Reference: https://github.com/WhiskeySockets/Baileys/blob/master/src/Utils/signal.ts

Atrocity M2.15 implements those structures and composes them into the `encrypt` IQ upload. Private key material never crosses the wire.
