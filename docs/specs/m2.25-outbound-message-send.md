# M2.25 — Outbound Message Send Pipeline

Outbound flow is explicit: serialize message → resolve recipient devices → encrypt per device → build `to/enc` envelopes → build outer `message` node → send.

Serialization, device resolution, Signal encryption, node assembly, and transport are injected boundaries.

A send result is returned only after transport succeeds.

Reference: https://github.com/WhiskeySockets/Baileys/blob/master/src/Socket/messages-send.ts
