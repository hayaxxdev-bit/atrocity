# M2.17 — Signed PreKey Rotation + Key-Bundle Digest

Current Baileys exposes signed-pre-key rotation and a digest query as separate
server-maintenance operations. Rotation creates the next signed pre-key id,
while digest validation requests the server's `encrypt` digest node.

References:
https://github.com/WhiskeySockets/Baileys/blob/master/src/Socket/socket.ts
https://github.com/WhiskeySockets/Baileys/blob/master/src/Utils/signal.ts

Atrocity M2.17 adds:
- signed pre-key rotation policy/operation;
- deterministic local key-bundle digest;
- constant-time digest equality;
- local-vs-server reconciliation result.

Important compatibility boundary: the exact WhatsApp server digest algorithm
and canonical server serialization are not asserted here without a captured
reference vector. The local digest is therefore an internal deterministic
fingerprint, not yet a claimed drop-in replacement for the server's digest.
