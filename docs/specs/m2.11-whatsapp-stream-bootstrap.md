# M2.11 — WhatsApp Stream Bootstrap Adapter

Current Baileys exposes the WhatsApp Web version tuple, browser/client
description, WebSocket URL, and connection configuration as explicit socket
configuration. Its socket sends binary nodes through WABinary and the Noise
frame layer.

References:
https://github.com/WhiskeySockets/Baileys/blob/master/src/Types/Socket.ts
https://github.com/WhiskeySockets/Baileys/blob/master/src/Defaults/index.ts
https://github.com/WhiskeySockets/Baileys/blob/master/src/Socket/socket.ts

M2.11 introduces a target adapter for stream-open node construction and raw
stream-feature retention/decoding.

The target-specific open attributes are explicit configuration. No claim is
made that the optional fields are universally required by the current server.
Exact wire vectors remain pending captured reference data.
