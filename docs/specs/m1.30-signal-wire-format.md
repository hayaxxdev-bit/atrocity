# M1.30 — Signal Wire Format Boundary

## Scope

M1.30 separates the logical Signal message from an encoded wire envelope.

The codec has a version field and carries:
- ratchet public key
- previous chain length
- message number
- ciphertext

## Important distinction

The codec in this milestone is an Atrocity wire envelope used to prove the
boundary between message cryptography and transport serialization.

It is **not** claimed to be the official WhatsApp `WhisperMessage` encoding.

## Properties

- explicit version
- strict required fields
- duplicate-field rejection
- unknown-field skipping
- size limits
- defensive copies
- malformed-input conversion to typed errors

## Next

Before this becomes a target-compatible Signal codec, the exact production
Signal/WhatsApp protobuf schema must be mapped from authoritative generated
schema/source and verified with byte-level fixtures.
